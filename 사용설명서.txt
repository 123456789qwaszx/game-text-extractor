게임 영상 텍스트 추출기 - 사용 설명서
==========================================

게임 플레이 녹화 영상에서 대사, 나레이션, 장소/시간 카드 같은 글자를 읽어
번역 작업용 엑셀 파일(원문 + 번역 빈칸 + 스크린샷)로 저장하는 프로그램입니다.
모든 처리는 내 PC에서 이루어지며 인터넷이나 유료 API를 쓰지 않습니다.


1. 설치 (처음 한 번만)
------------------------------------------
1) 압축을 원하는 곳에 풉니다. (예: 바탕화면\게임텍스트추출기)
2) '설치.bat'을 더블클릭합니다.
   - Python이 없으면 자동으로 설치합니다.
   - 필요한 부품을 내려받습니다. (약 300MB, 몇 분 걸림)
   - 글자 인식 엔진 Tesseract를 설치합니다. 관리자 권한 창이 뜨면 '예'를 누르세요.
   - 마지막에 '모든 항목이 정상입니다'가 나오면 설치가 끝난 것입니다.
3) 바탕화면에 '게임 텍스트 추출기' 바로가기가 생깁니다.

※ Windows 보안 경고(SmartScreen)가 뜨면 '추가 정보' → '실행'을 누르세요.


2. 기본 사용법
------------------------------------------
1) '실행.bat'(또는 바탕화면 바로가기)으로 프로그램을 엽니다.
2) ① [영상 추가]로 녹화 영상을 고릅니다. 여러 개를 한 번에 넣을 수 있습니다.
3) ② 게임 프로필을 고릅니다.
   - '샘플게임 (Google Play PC 1080p)'은 함께 보내 드린 영상의 게임에 맞춘 설정입니다.
   - 다른 게임은 아래 '3. 새 게임 설정하기'를 따라 프로필을 만드세요.
4) ③ 저장 위치를 고릅니다. 비워 두면 영상과 같은 폴더에 저장합니다.
5) [▶ 추출 시작]을 누릅니다. 끝나면 [결과 엑셀 열기]로 결과를 엽니다.

처리 시간: 영상 길이의 약 0.3~1배 (PC 성능에 따라 다름)


3. 새 게임 설정하기 (게임마다 한 번)
------------------------------------------
게임마다 대사창 위치가 다르므로, 처음 한 번 '어디를 읽을지'를 알려 줘야 합니다.

1) 그 게임의 영상을 ①에 추가하고 [새 프로필 만들기]를 누릅니다.
2) 위쪽 슬라이더로 대사가 화면에 다 나온 장면을 찾습니다.
3) 오른쪽 '영역 그리기' 탭에서 종류를 고른 뒤, 화면 위를 마우스로 드래그해 네모를 그립니다.

   - 텍스트 영역 (필수, 초록): 글자를 읽을 전체 범위.
       대사창, 컷신 대사, 나레이션, 장소 카드가 나오는 곳을 모두 포함하도록 넉넉히 그립니다.
       '화자가 있을 때/없을 때 형태 이름'은 엑셀의 '형태' 칸에 들어갈 이름입니다.
   - 화자 이름 (파랑): 이름표 자리. 컷신처럼 이름 위치가 다른 화면이 있으면 여러 개 그립니다.
       이 자리에서 시작하는 글자는 '화자' 칸으로 들어갑니다.
   - 별도 분류 (주황): 장소/시간 카드, 시스템 메시지처럼 대사와 따로 뽑을 자리.
   - 무시 (회색 점선): 깜빡이는 '다음' 아이콘, 고정된 버튼 글자 등 읽지 않을 자리.

   ※ 영역은 '줄이 시작되는 위치'로 판단합니다. 화자 이름 칸은 이름표만 감싸도록 작게 그리세요.

4) [이 화면으로 인식 테스트]를 누르면 화면에 읽은 줄이 표시되고 오른쪽에 결과가 나옵니다.
   (파랑 = 화자, 초록 = 본문, 주황 = 별도 분류)
   대사창, 컷신, 나레이션 등 화면 종류마다 슬라이더로 옮겨 가며 테스트해 보세요.
5) 프로필 이름을 정하고 [저장]을 누릅니다.

'인식 설정' 탭
   - 언어: 한국어 게임은 kor. 문장 속 영문(플레이어 이름 등)은 자동으로 영어로도 다시 읽습니다.
           영어 게임은 eng. 일본어 등은 아래 '7. 다른 언어'를 보세요.
   - 말줄임표: '......', '…' 등을 어떤 형태로 통일할지.
   - 줄바꿈 연결: auto(권장) = 자동 줄바꿈으로 잘린 줄을 한국어 띄어쓰기까지 판단해 이어 붙임.
   - 초당 검사 횟수: 대사를 빠르게 넘긴 영상이면 높게(10~15). 기본 10.
   - 결과 바꾸기: 한 줄에 하나씩 '원래 => 바꿀 값'.
       예) hill => {PLAYER}        (플레이어 닉네임을 번역용 변수로)
       예) 취황의 갈날 => 취황의 칼날  (자주 틀리는 고유명사 교정)


4. 결과 엑셀 보는 법
------------------------------------------
[텍스트] 시트
   No / 시간 / 형태 / 화자 / 원문 / 번역(초록, 빈칸) / 메모 / 확인 / 신뢰도 / 스크린샷 / 원본
   - 노란색 원문 = 확인이 필요한 줄입니다. '확인' 칸에 이유가 적혀 있습니다.
       · 인식 신뢰도 낮음: 글자를 잘못 읽었을 수 있음
       · 본문 인식 안 됨: 화자는 읽었지만 본문을 못 읽음 (대개 '......'만 있는 대사)
       · 문장 끝 확인: 대사가 끝까지 나오기 전에 넘어갔을 수 있음
       · 화면 전환 중에 읽음: 화면이 바뀌는 도중에 한 번만 읽힌 줄
       · 화자명 확인: 비슷한 이름이 있어 오인식일 수 있음
   - '스크린샷' 칸의 그림과 비교하며 원문을 고친 뒤 번역하세요.
   - '원본 열기'를 누르면 그 장면 전체 화면이 열립니다.
     (엑셀 파일과 '_스크린샷' 폴더를 같은 위치에 두어야 합니다)
[화자 목록] 시트: 등장인물 이름 목록. '번역명' 칸에 이름 번역을 정리해 용어집으로 쓰세요.
[정보] 시트: 영상, 프로필, 추출 조건 기록.


5. 녹화 팁 (정확도를 높이려면)
------------------------------------------
- 원본 해상도(1080p 이상)로, 화질을 높게 설정해 녹화하세요. 압축이 심하면 글자가 뭉개집니다.
- 대사를 너무 빨리 넘기지 마세요. 각 대사가 다 나온 뒤 0.5초 정도만 머물러도 충분합니다.
- 자동 진행(오토) 모드로 녹화하면 가장 안정적으로 추출됩니다.
- 화면 크기/해상도가 같다면 녹화 프로그램이 달라도 같은 프로필을 쓸 수 있습니다.


6. 문제 해결
------------------------------------------
- 프로그램이 바로 꺼짐: '실행(오류확인용).bat'으로 실행해 오류 내용을 확인하세요.
  오류 기록은 이 폴더의 error.log에도 저장됩니다.
- 'Tesseract를 찾을 수 없습니다': [설정] → [Tesseract 위치 지정]에서
  C:\Program Files\Tesseract-OCR\tesseract.exe 를 지정하세요.
- 설치 상태 확인: 이 폴더에서 주소창에 cmd 입력 후
  .venv\Scripts\python.exe -m app.selftest
- 특정 장면이 빠짐: 프로필의 '초당 검사 횟수'를 15로 올리거나,
  텍스트 영역이 그 장면의 글자를 모두 포함하는지 인식 테스트로 확인하세요.
- 엉뚱한 글자가 섞임: 배경 무늬나 아이콘 자리에 '무시' 영역을 그리세요.


7. 다른 언어
------------------------------------------
models\tessdata 폴더에 언어 파일(.traineddata)을 넣으면 '언어' 목록에 나타납니다.
   https://github.com/tesseract-ocr/tessdata_best  에서 받을 수 있습니다.
   예) 일본어 jpn.traineddata, 중국어 간체 chi_sim.traineddata
여러 언어를 함께 쓰려면 언어 칸에 kor+jpn 처럼 적습니다.


8. 명령줄로 여러 영상 한꺼번에 처리 (선택)
------------------------------------------
.venv\Scripts\python.exe -m app.cli 영상1.mp4 영상2.mp4 -p "profiles\샘플게임_1080p.json" -o 결과폴더


9. 구성
------------------------------------------
app\core     추출 엔진 (영상 읽기, 변화 감지, 글자 인식, 정리, 엑셀 저장)
app\gui      화면 (메인 창, 영역 편집기)
models       글자 위치 검출 모델(PP-OCRv5), Tesseract 언어 파일
profiles     게임별 설정 파일 (.json)
